# Contributing to ANKA

Thank you for your interest in contributing to ANKA!

ANKA is an independent technology initiative focused on artificial intelligence, robotics, software engineering, automation, and research.

## 1. Getting Started

Before contributing:
- Read the project's README and documentation.
- Check existing issues and discussions.
- Contact the maintainers before proposing major changes.
- Respect repository permissions and project scope.

## 2. How to Contribute

You can contribute by:
- Reporting bugs and technical problems.
- Suggesting new features.
- Improving documentation.
- Testing applications and prototypes.
- Submitting code improvements.
- Participating in technical discussions.

## 3. Code Contributions

When submitting code:
1. Open an issue or discuss the proposed change when appropriate.
2. Create a separate branch for your work.
3. Write clear and maintainable code.
4. Include relevant tests.
5. Submit a pull request with a detailed description.
6. Wait for review before merging.

## 4. Security

Do not publicly disclose security vulnerabilities.

Report security concerns privately to:
support.anka@proton.me

Never commit passwords, API keys, access tokens, or confidential information.

## 5. Intellectual Property

Only contribute code or materials you have the right to share.

Respect third-party licenses, copyrights, trademarks, and confidential information.

Submitting a contribution does not automatically grant access to private repositories or transfer ownership of unrelated projects.

## 6. Community Standards

All contributors must:
- Communicate respectfully.
- Avoid harassment and discrimination.
- Respect different experience levels.
- Provide constructive technical feedback.
- Follow applicable laws and platform policies.

## 7. Project Governance

Project maintainers review and decide whether contributions are accepted.

Major architectural and security changes require maintainer approval.

## 8. Contact

For questions, collaboration proposals, and technical communication:

Email: support.anka@proton.me

GitHub: https://github.com/anka-organization
