# ANKA Security Policy

## 1. Introduction

ANKA is an independent technology initiative focused on artificial intelligence, robotics, software engineering, automation, and technology research.

We are committed to improving the security, reliability, and integrity of our projects.

This policy explains how security vulnerabilities should be reported and handled.

## 2. Reporting Security Vulnerabilities

If you discover a potential security vulnerability in an ANKA project, please report it privately.

**Security Contact:** support.anka@proton.me

**GitHub Organization:** https://github.com/anka-organization

When reporting a vulnerability, please include:

- The affected project or repository.
- A detailed description of the vulnerability.
- Steps to reproduce the issue, if available.
- The potential security impact.
- Relevant technical information.
- Suggested solutions, if known.

Please do not submit sensitive security reports through public GitHub Issues.

## 3. Responsible Disclosure

We ask security researchers and contributors to follow responsible disclosure practices.

Please:

- Report vulnerabilities privately.
- Avoid accessing information without authorization.
- Do not disrupt services or systems.
- Do not publicly disclose vulnerabilities before coordinating with ANKA.
- Respect the privacy of users and contributors.

## 4. Security Review Process

ANKA aims to evaluate reported vulnerabilities according to their potential impact and available resources.

Our general process includes:

1. Receiving the security report.
2. Reviewing the technical information.
3. Assessing the potential impact.
4. Identifying possible solutions.
5. Implementing appropriate fixes where feasible.
6. Communicating relevant updates when possible.

ANKA does not currently guarantee specific response or resolution times.

## 5. Supported Projects and Versions

Security support depends on the development status of each ANKA project.

Projects currently being researched or developed may not have stable public releases or guaranteed security updates.

Supported versions and security maintenance policies may be specified separately in each project repository.

## 6. Secure Development Practices

ANKA encourages contributors to follow secure development practices:

- Never publish passwords, API keys, or access tokens.
- Protect confidential project information.
- Use appropriate authentication and authorization.
- Review code changes before deployment.
- Keep software dependencies updated where feasible.
- Report suspected security incidents promptly.
- Follow applicable laws and third-party software licenses.

## 7. Confidentiality and Privacy

Security reports should contain only the information necessary to investigate the issue.

Do not submit personal information, private credentials, or confidential third-party data unless specifically authorized and necessary.

## 8. Security Limitations

ANKA is an independent technology initiative and is not currently a registered company.

Security resources and response availability may be limited. Publication of this policy does not constitute a guarantee that all projects are free of vulnerabilities.
